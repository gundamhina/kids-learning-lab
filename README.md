# Kids Learning Lab

原名「注音救援隊」，2026-10 擴大成注音、數學、英文、動腦四科後改名，網址跟著改成 https://gundamhina.github.io/kids-learning-lab/ （舊網址已停用）。同一個瀏覽器裡的存檔照舊讀得到。

給 5 歲孩子的學習遊戲：注音、數學、英文、動腦四科，每科幾種小遊戲，平板和觸控螢幕還能兩個人對戰。會依她的弱點自動調整出題，家長可以看進度、調難度、限制每天玩幾局。

## 玩

先 `npm run build` 產生 `dist`（`dist/` 不進 git），再把整個資料夾複製到要玩的電腦，用 Chrome 開 `dist/index.html`。不用安裝、不用網路。`index.html` 旁邊的 `audio`、`img` 資料夾要一起帶著。

- 第一次進去先新增一個人，之後開機直接進上次那個人的首頁。
- 離線也能玩：每台裝置有網路時打開一次，就會把整個遊戲（網頁、錄音、圖，約 11 MB）存進裝置（`sw.js`）；之後沒網路也打得開。有網路時一律先拿最新版。沒網路時唸唸看會先藏起來（語音辨識要連網）。
- 首頁先選科目（注音、數學、英文、動腦），再選玩法（網頁一層分區、手機兩層）。答錯照三級提示：錯 1 次搖一下、重唸題目（「看」的練習只搖）；錯 2 次起正解一直發亮；錯 3 次起再示範。
- 注音：
  - 聽：釣魚、打地鼠（聽音選符號）、翻牌（配對複習，不記進度）
  - 看：符號找朋友（看符號，從三張圖選第一個字有這個音的）、連連看（詞的注音連到圖）、填空（少一個音節）、聲調填空（少一個調號，專出聲調難分辨的詞）
  - 寫：注音表（三頁：37 個符號照課本分組排、22 個結合韻、5 個聲調；點一個就放大照筆順寫一次（聲調是放大成例字 ㄇㄚ）、唸出來，不記進度）、學寫字（照教育部筆順一筆一筆教，寫錯會說錯在哪：方向反了、寫成別的筆；不記進度）、寫寫看（低階描寫、高階聽寫；寫錯照筆順公布答案，可按「教我寫」；不會寫可以先按眼睛「不會寫」看答案，記成不會）、拼拼看（聽一個音，照順序把符號拖進牌子上的空格拼出來；結合韻和拼讀字一組一組解鎖）
  - 說：唸唸看（看注音唸出來，用 Chrome 語音辨識，要連網，只記唸對）
- 數學：數一數（數框裡幾個，選數字卡；點東西會一個一個數；第 4 階起框裡混兩三種東西，只數左上角那一種）、做數量（把東西放進盒子）、比多少（哪邊多、哪邊少；第 5 階起多一個「一樣多」）、加減（十以內，加到 5 → 5 以內減 → 加到 10 → 10 以內減，一組一組開；第 1～2 階只有圖、第 3～4 階數字配圖、第 5～6 階只有數字）、寫數字（0～9 照筆順描，純練習）。範圍 1～5／10／20 由家長設。
- 英文：認字母（看字母選開頭是它的圖）、聽字母（聽一個字母選卡片）、拼單字（看圖聽單字，把字母拖進格子）、寫字母（A～Z 照筆順描，純練習）。英文用瀏覽器的英文語音。
- 動腦：找規律（補空格、找重複、換一組圖）、圖形類比、拼板補洞、找不同（幾張卡找不一樣的）、經典找不同（兩張圖找 3～5 個差異）、迷宮（撿骨頭再回家），畫畫：著色（點一塊塗滿，純練習）。
- 對戰（只有平板、觸控螢幕會出現，首頁右下角）：兩個人擠一台螢幕各答各的，先答對 5／8／10 題的贏。版面可選左右坐或面對面（上半邊轉 180 度）。每邊選一個使用者（照自己的進度出題）或客人（程度 1～6 星）。玩法：符號找朋友、看注音找圖、數一數、比多少、認字母、看圖找字母、找規律、找不同、圖形類比、拼板補洞；聽的玩法兩邊聲音會疊在一起，不做對戰版。不記練習紀錄，使用者贏了 10 根骨頭、輸了 5 根。
- 出題：越不熟越常出，出現不到 3 次的優先；熟了（4 顆星）的隔 3、7、14、30 天再考一次。
- 內容：37 個符號、22 個結合韻、353 個拼讀字（帶聲調）、437 個有圖的詞、243 個只聽不看圖的詞（只給聲調填空）。讀音照教育部《國語辭典簡編本》。
- 紀錄分十六軌，各自升降難度：注音七軌（聽、讀、寫、詞、調、拼、認），數學三軌（數、比、算），英文兩軌（字、拼英），動腦四軌（律、異、找、迷）。
- 老師帳號：給教室投影用，首頁直接選難度、範圍和打地鼠速度（慢／中／快），不記紀錄、沒有骨頭商店。
- 右上角齒輪 2 秒內連點三下進家長區：學習設定（每局題數、數數範圍、每天玩幾局、延長幾局）、學習統計（練習日曆、每天幾分鐘、各軌第一次就答對的比例、筆順最常錯在哪）、弱項練習、進度、難度、練習範圍、使用者管理、匯出匯入。
- 每天玩幾局（預設不限）：玩滿就是晚上的收尾畫面，給一個離開螢幕的小任務；大人算對一題加法才能延長。
- 進度存在那台電腦的 Chrome 裡，換電腦要用家長區的匯出／匯入。

## 開發

```bash
npm test          # 單元測試（node 內建 test runner，零相依）
npm run build     # 把 src/ 合成 dist/index.html，並複製 audio/、img/
```

`src/` 是分檔的原始碼，`dist/` 是 build 出來的交付物（不進 git，GitHub Pages 由 CI 自己 build）。發音檔在 `audio/`（教育部手冊官方錄音，CC BY 4.0），圖在 `img/`（生圖後用 `tools/prep_images.py` 整理）。設計文件在 `docs/superpowers/specs/`。

資料來源：
- 發音：教育部《國語注音符號手冊》錄音，CC BY 4.0。結合韻的 21 個音檔是用微軟神經網路語音預先產生的（見 `audio/README.md`）。
- 詞與拼讀字的讀音：教育部《國語辭典簡編本》，CC BY-ND 3.0 臺灣；用 `tools/check_moe.py` 核對。
- 詞的圖：Twemoji（https://github.com/jdecked/twemoji），CC BY 4.0；`tools/fetch_twemoji.py` 下載到 `img/emoji/`。手繪詞圖放 `img/words/` 會優先顯示。
- 注音筆順：教育部《國字標準字體筆順學習網》，CC BY-NC-ND 3.0 臺灣。原始資料原封不動存在 `tools/moe_strokes.json`，`tools/gen_strokes.py` 只換成 SVG 路徑寫法產生 `src/strokes.js`。


## 部署到 Northflank（備用，目前沒在用）

根目錄的 `Dockerfile` 兩段式：node 跑 `npm run build` 合成 `dist/`，再用 nginx 端出來，聽 8080。nginx 設定在 `deploy/nginx.conf`（index.html 不快取，錄音和圖片快取 30 天）。

Northflank 上建服務：Combined service → Git repo 選 `gundamhina/kids-learning-lab`、分支 `master` → Build type 選 Dockerfile（路徑 `/Dockerfile`）→ Networking 加一個 port `8080`、HTTP、Public → 最小的 compute plan 就夠。之後每次 push master 會自動重建。

注意：存檔在瀏覽器 localStorage，綁網址。從本機 `dist/index.html` 換到 Northflank 網址時，先在舊的那邊家長區「匯出」，到新網址「匯入」。語音辨識要 HTTPS，Northflank 給的網址本來就是。


## 體驗

- **手感**：答對時星星從答對的東西爆開、骨頭飛進上方計數器、手機輕震。連續第一次就答對會出現火焰加數字，連 3 題、連 5 題有額外骨頭（照階級）。特效在 `src/fx.js`。
- **教學**：每個玩法第一次玩先放小手示範動畫，按播放鍵才開始；遊戲左上的「？」可以再看。動畫在 `src/tutorial.js`，樣式在 `style.css` 的 `.tut-*`。
- **每日目標**：首頁上方火焰是連續天數，十個腳印是今天玩了幾局（翻牌不算），蓋滿開寶箱拿骨頭（30 根起，連續每天多 5 根，最多 60）。
- **今天推薦**：首頁發光的那張卡，是今天練最少的那一軌。
- **背景音樂**：只在選人、首頁、商店、結算放，進遊戲就停；首頁左下角可以關。

## 骨頭與商店

答對賺骨頭，照題目難度給：階級越高給越多，還不熟的符號多給、已經很熟的少給；連對和玩完一局的獎勵也照階級（規則在 `src/scheduler.js` 的 `questionReward`）。首頁上方「商店」用骨頭買東西。翻牌是純遊玩，不算進星星和難度，骨頭只有配對一對 1 根。商店兩個分頁：

- **配件** 十六件（180～1650 根），分頭上、臉上、脖子、背後，每個部位戴一件，戴在正在出任務的那位隊員身上，首頁、遊戲、結算都看得到。表在 `src/art.js` 的 `ACCESSORIES`，每件是畫在隊員 260×300 框裡的 SVG，每位隊員記了頭頂、兩眼中間、脖子的位置，配件照著移過去（背後那三件畫到框外才露得出來）。
- **救援隊員** 六位原創隊員（警察柴犬、消防象、醫護兔、森林熊、工程河狸、廚師貓，`DOG_NAMES`），商店賣自己那位以外的五位，1800 到 5400 根。買回家後站在首頁草地上、結算時一起跳舞；首頁下方隊員列點誰，誰就出任務（存在存檔的 `partner`）。

買之前會跳確認框（大大的商品圖和價格，紅叉叉不買、綠打勾買）。商店畫面在 `src/shop.js`，家長區可以加減骨頭。隊員圖是 `img/dog-0.png` 到 `dog-5.png`（檔名沿用舊的 dog）。`build.js` 會比對哪幾張還是 dog-0 的複本，只有複本才在 `dogSvg` 多畫一條隊色領巾來分辨；現在六張都是各自的圖，領巾不會出現。

## 手機

舞台會跟著螢幕比例變形，不留邊：橫的高固定 800、寬 1200～1800，畫面元素排在正中央 1200×800 的 `.frame` 裡，背景鋪滿整個舞台；直的寬固定 800、高 1100～1800，每個畫面另有直版排法（CSS 的 `#stage.portrait` 加上各遊戲的 `layout()`）。舞台大小在 `STAGE`（ui.js），也寫成 CSS 變數 `--W`、`--H`。座標換算一律用 `stagePoint()`／`framePoint()`。背景用 `bgHtml()` 產生、`layoutBg()` 定位：草原蓋滿舞台，碼頭那張橫的靠左蓋滿、直的放大到占畫面下半貼左下、上面補天空色（釣魚的狗狗跟碼頭放在同一層，一起縮放）。手機碰畫面會進全螢幕（Android Chrome）。要更像 app 就用瀏覽器選單「加到主畫面」，`src/manifest.webmanifest` 設了全螢幕與橫向，圖示由 `tools/make_icons.py` 從 dog-0 做出來。

## 部署到 GitHub Pages（目前用這個）

repo 設成公開後，`.github/workflows/pages.yml` 會在每次 push master 時跑測試、build、部署到 https://gundamhina.github.io/kids-learning-lab/ 。第一次跑會自動把 Pages 打開；如果沒有，到 repo 的 Settings → Pages，Source 選 GitHub Actions。
